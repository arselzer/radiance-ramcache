# Status

The current source is engine `7bfa66ad`. This is a research checkpoint for DeepSeek-V4.1-Flash on four RX 9070 XT cards with CPU-computed experts. Its evidence runs through window `ab-20261030T213623Z`. Since 30 Oct the box has 256 GB of RAM (8 x 32 GB DDR4-2666); windows before `ab-20261030T194552Z` ran on 128 GB (8 x 16 GB DDR4-2133).

The windows ran on a box shared with a production service (QFN). Each window logs its stop and its restoration, with a test completion.
