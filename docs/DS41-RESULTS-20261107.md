## C2 DSpark: measured code gain

Fixed 131,072 context, N1/C1, 192 GiB expert cache, 2,048-token chunks,
Lc2048/P1/Qe64/Rb/Vp/Cs/Ada/Li64/J0/Y0/Qpr0. The optional worker is unused. CODE uses two plain
endpoints enclosing two DSpark repeats; chat is an exploratory single pair.

Both sides below use a **2,048 MiB pinned HOST pool per GPU**. The plain 256 MiB pool
was not included in this window. These gains are relative to the tested plain baseline;
comparison with the best plain configuration awaits the four-condition pool/bank/drafting test.

| CODE16, cap256 | 24.8146 | 28.5933 | +15.23% |
| CHAT16, cap64 | 24.5513 | 25.2282 | +2.76% |

Each rate divides total generated tokens by total decode time for an arm; CODE averages its two
same-treatment arm rates. All 96 original replies and original prompt/generated counts matched.
The code endpoints drifted 0.0128%, below the predeclared 5%; both rate estimators passed their
gate. All six servers joined without forced stops. Native-FIRST, policy/origin checks and normal
production restoration passed. Required query/policy/observer/wait costs remain paid; raw
target/state/timeline capture was disabled for timing.

This is a matched gain on this workload/profile. It does not replace the older held-out/concurrent
table or establish concurrent, auxiliary-card, prefix-cache or growing-KV DSpark qualification.

## 96 GiB cache does not mean 128 GB machine validation

The 96 GiB test ran on the current 256 GB server. It establishes reduced-cache exactness/activity in
the stated scope and the diagnostic timings above. It does not establish whole-machine peak
memory, headroom or throughput on 128 GB. The larger host can retain different OS page cache,
temporary/staging space and room for other processes. Variable RAM budgets remain supported.

For historical context only, the Oct 30 legacy profile measured 19.9 tok/s with 96 GiB cache on 128 GB
DDR4-2133 versus 20.9 tok/s with that cache on the upgraded 256 GB DDR4-2666 host. Those old-profile
rates are not modern token-weighted C2 results or a validation of the current 128 GB configuration.
