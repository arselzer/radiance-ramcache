Review findings repaired before this freeze
  - Session enter rejects layers outside3..44 before signed layer-3 arithmetic,
    including INT_MIN; the new authored checker covers that boundary.
  - Routing parity remains two WTAB classes with expert%2, distinct from one
    Native record geometry class. No actual router geometry was changed.
  - An idle stop could previously observe no frame, then allow begin after
    workers exited. stop_admission now shares pass_mutex with begin, permanently
    closes idle admission, and exits88 for an active frame. Engine calls it before
    worker abort. If idle close wins, model_phase returns before worker release
    and the caller exits before sampler/publication. There is no new begin after
    a closed Session. This fixes the identified ordering race by source evidence.
