# P1 read-ahead and the GPU slot comparison, 2 Nov 2026

The GPU slot change produced no observed prefill speedup in the matched current43 run. A separate exact P1 read-ahead experiment found a repeatable long-prompt improvement from setting `RADIANCE_EXPERIMENTAL_DS41_P1_AHEAD=0`. Runtime defaults, installed files and production configuration remain unchanged.

Both comparisons use four RX9070XTs, 192GiB expert RAM, current43 engine and its unchanged five plugins, P1/Lc2048/B6/Mr32/Qm320/Rb/Vp/Cs, FP8 conversion off, BF16 KV and the original82/3086/6817-token requests with cap16. Prefix cache is off; every cache count is0. The unchanged client retains its10Hz stats observer. Each timing arm uses a fresh server; TTFT includes the first generated token. Model loading is about75s per instance.

The setting removes speculative I/O scheduling from an existing path, without changing weights, routes, arithmetic or reductions. No engine/kernel build or source behavior change was introduced.

This is a measured long-prefill tuning candidate for the current four-XT/192GiB configuration. Prefix/harness/lifecycle/concurrent and smaller-budget scope is not newly qualified. Variable cache and VRAM budgets remain supported. Broad default adoption and publication have not occurred.
