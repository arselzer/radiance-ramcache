Experimental DeepSeek native packed kernels/oracle (not full serving support)

libds41 supplies dense ds41_gemm_packed and routed ds41_routed_packed operations
for IQ2_XXS, IQ2_XS, IQ2_S, IQ3_XXS, Q5_K and Q8_0. They use the exact native
layouts in GGUF_REPACK.txt. Activations/output may be f32/f16/bf16; accumulation
is f32, with one final nearest-even output rounding. No weight expansion is
stored, and no additional activation/cache quantization is introduced.

These are simple correctness baselines, not optimized prefill kernels: wave32
owns one output and four waves share a workgroup. Lanes accumulate ascending
strided K then reduce in a fixed tree. CPU oracle accumulation is ascending K,
so floating-point reduction differences are expected. No WMMA, speculative
decoding, fused SwiGLU, mixed-expert-format dispatch or performance claim is made.
The graph must perform original clamp/mixture-before-down rounding semantics.

The scalar decoder is shared by host/device but independently tested against
GGML goldens and the core's generic canonical decoder. Codebooks preserve the
GGML MIT notice. The module needs no plugin initialization or persistent scratch.
Launches allocate/synchronize nothing. It is built only for gfx1201 wave32.

Build isolation

RAD_BUILD_DS41_EXPERIMENTAL defaults OFF. With it ON, libds41_ref (host oracle)
and, in a HIP build, libds41 are emitted under experimental/kernels. They are
not installed or placed in the ordinary serving scan. No architecture is
registered and the running service/config/image are not changed.

For offline compilation alone, from the source root:
  bash libds41/build-offline.sh
This compiles libds41.so and explicitly gated packed/cache, math, compressor and
native Engram checkers under build-ds41-offline.
Explicit gfx1201 target and hidden devices avoid device enumeration/execution.
The script does not load either artifact or run tests. Current host toolchain is
HIP 7.1 / LLVM 21; this artifact links libamdhip64.so.7. A production image needs
an explicit compatible build against its own runtime/toolchain, not a blind copy.

Operation contracts

Dense required parameters: M (row capacity), N, K, format, a_dtype, y_dtype.
Canonical format strings are iq2_xxs, iq2_xs, iq2_s, iq3_xxs, q5_K, q8_0.
Scalar dtype strings are f32, f16, bf16. The geometry must be positive, native
K-block aligned and within the checked signed/grid limits. Operands:
  a: [actual_M,K], unit column stride and row pitch >= K
  w: core logical [N,K], private stored dtype ds41.gguf.<format>.v1; or an explicit
     standalone U8 [N,native_row_bytes] view of contiguous native layout
  y: [actual_M,N], unit column stride and row pitch >= N
actual_M may be less than frozen M capacity. Output/input aliases are refused.
The ABI provides geometry, not allocation capacities; the caller must back it.

Routed adds R (job capacity), n_expert. It produces one output per routing job,
with no sum/atomic writes and no implicit weighting. Operands:
  a: [actual_input_rows,K], actual_input_rows <= M
  w: RAD_WTAB of expert entries; runtime private dtype [E,N,K], stride[0]=0;
     standalone explicit U8 [E,N,native_row_bytes] is also supported
  expert_ids: I32 [actual_R], each in [0,E)
  row_ids: I32 [actual_R], each in [0,actual_input_rows)
  y: [actual_R,N], actual_R <= R
  status: I32 [actual_R]
Routing order/repeated input rows are explicit. Every selected pointer must stay
valid until its stream finishes; output/status must not alias selected weights.
Host reference validates every ID/pointer before writing outputs. Device guards
invalid IDs or null selected pointers, writes NaN to that job and a negative
status; valid jobs may still complete. Future graph code MUST check status before
committing a request. Error status is diagnostic, not an integrated abort path.

The actual core retains logical N,K shape/strides while changing stored dtype.
Private dtype prevents scalar diagnostics from treating packed bytes as a dense
logical U8 matrix. Physical extents remain N*native_row_bytes. The runtime
Builder/Ctx regression checks the actual binding and table refresh after movement.
Plain U8 [N,K] is refused; it is not a supported alias for the opaque layout.

Both schemas use all-plane host layout/relayout/unrelayout hooks, validating
format, operand role and actual N/K. Ordinary scalar weights/tables are not
compatible aliases. Shape hooks deliberately refuse a cold random weight draw:
normal F32 bytes are not a canonical IQ encoding. Use recorded importer fixtures
or the dedicated checker instead of pretending to test a fake dtype.

Validation gates

Host tests ds41_packed_decode_test and ds41_packed_kernel_test cover all formats,
the nine input/output dtype pairs, arbitrary block indices, pitches, routes,
rounding, malformed geometry and actual ABI layout hooks.

The dedicated selftest passed 348 tiny dense/routed and 33 latent-cache cases on
one gfx1201 in the approved idle window. This includes error routes, guards around
every allocation, read-only input checks, private logical descriptors and CPU
oracle comparison. Separate checkers passed 141 math and 167 persistent compressor
GPU cases. They perform GPU work ONLY with explicit --run-gpu and are never
CTest entries. Reproduction requires another approved idle window:
  build-ds41-offline/ds41-packed-selftest --run-gpu build-ds41-offline/libds41.so 0
The final argument selects a visible gfx1201 device. Running it does not stop
the server automatically; the operator must arrange the approved idle window.
It checks small kernels, not TP4 inference, model quality, capacity or throughput.

Production integration remains open

Scalar GPU math/mHC, ratio-1/2 compression and bit-exact latent copies are now
implemented and checked in isolation. The complete attention/index path, graph,
exact dense gathers, bounded Engram runtime binding, status propagation,
cancellation, prefix and speculative state remain unconnected. See
DEEPSEEK41_STATE_LAYOUT.txt for the compressed-cache representation and current
WINDOW+LINEAR prefix limitation. Core U32 LINEAR checkpoint tests preserve pending
values/exact cursor bits and match continuous C2 pooling after cross-slot resume.
That does not enable combined WINDOW+LINEAR prefix reuse or speculation.

Unequal expert shards can produce different resident masks. Runtime audit found
local weight pointers/events, so matching masks are an optional initial policy,
not a demonstrated universal correctness requirement. A conservative optional
joint planner converges on a common initial set without padding; it is unwired
from Engine/heat and makes no throughput promise.

The standalone native HIP Engram adapter passes its tiny ownership/fence check,
but its private HIP stream/events cannot be attached directly to core AQL streams.
See arch/deepseek41/engram_runtime_integration.README.txt. The future graph must
use core-compatible stream/event ordering and checked allocation ownership.

Lossless weight bytes do not establish official FP4/FP8 activation/cache
arithmetic equivalence, model quality, 262K capacity or inference speed. Those
remain separate full-model correctness, allocation and quality gates.
