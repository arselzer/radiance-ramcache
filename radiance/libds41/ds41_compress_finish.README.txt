Experimental masked compressor completion: ds41_compress_finish

This fills a specific floating-topology pipeline gap: compress_pool emits sparse
completed C1/C2 rows, while ordinary full-T projection inputs must all be defined.
It does not implement official activation QDQ, pending compressor state, I/O,
compaction, cache allocation/store, a DS41 graph or serving lifecycle. Full-T
index-K projection may consume the defined unrotated output; every downstream
finish/store must still honor emit. Inactive zeros are not completed cache rows.

Fixed7 operands, in this order:
  pooled0        [actualT,n]            a_dtype=f32/f16/bf16, IN
  emit1          [actualT]              I32, IN, exactly0 or1
  first_positions2 [actualT]            I32, IN
  gain3          [n]                    F32, IN
  pairs4         [P,rotary_dim/2,2]      F32, IN, forward cosine/sine
  unrotated5     [actualT,n]            dtype=f32/f16/bf16, OUT
  rotated6       [actualT,n]            dtype=f32/f16/bf16, OUT

Required parameters M(capacity),n,rotary_dim,ratio,a_dtype,dtype,eps. Ratio is1 or2;
actualT1..M, M<=65536, n<=1024, rotary_dim positive/even<=n, P1..1048576, finite
eps>0. This is one latent head, not arbitrary multi-head RoPE. Element views may
have positive nonoverlapping pitches, checked by the existing math::tensor helper.
Position/table extents are in original-token coordinates, never compressed-row
coordinates. Every ACTIVE first position must satisfy0<=position<P and
position%ratio==0. No inactive pooled, first-position or pair payload is read.
All gain elements and emit values are checked even when every row is inactive.

For an active row, in explicit ascending-d F32 RMS order:
  x = cast_to_activation_dtype(pooled)
  inverse = 1/sqrt(sum_d(x[d]*x[d])/n + eps)
  u[d] = cast_to_activation_dtype((x[d]*inverse)*gain[d])
  unrotated = u
  rotated prefix = exact same u bits
  rotated tail adjacent pair = cast_to_activation_dtype(
      [u_even*cos - u_odd*sin, u_even*sin + u_odd*cos])
The rotation consumes the ROUNDED u, not an unrounded normalization result.
Encoding an already-rounded scalar to its output storage is idempotent; no extra
intermediate precision boundary is introduced. Inactive rows write exact positive
zero in both outputs, including F16/BF16. There is no normalization of pair
coefficients; referenced finite cosine/sine pairs must already be unit within
2e-5, matching the existing explicit RoPE baseline. Unreferenced table rows may
contain arbitrary bits. Single source activation precision is explicit; this is
not an official quantization/quality equivalence claim.

Before ANY output byte is written, the whole batch checks masks, gains, active
positions, active pooled values, the input activation cast, RMS square/sum/inverse,
normalized values and output casts, referenced pair coefficients, and rotated
values/output casts. A finite F32 input that overflows a F16/BF16 activation cast
is refused. Intermediate square/sum overflow is refused. Outputs remain unchanged
for every payload refusal, including previously inactive rows that would otherwise
have been zeroed. Metadata refusals precede payload access and leave status and
outputs untouched. Concurrent caller mutation of inputs is outside this contract.

Outputs must be disjoint from every other operand and from each other; overlapping
read-only inputs are allowed. Checked spans include strided padding. All pointer
ends, products, shapes, alignments and semantic4-byte scratch overlaps are checked
before use. GPU staging additionally checks the ENTIRE rounded scratch reserve
against all seven operand spans before its first chunk enqueue, preserving prefix
and final partial-Plan tail canaries through ds41_device_plan's256-byte transport.
No kernel receives Plan by value. Only small pointer/count kernel arguments cross
the AQL ABI; actual compiled segment acceptance still needs the parent's AQL gate.

Status/native scratch:
  semantic emulator: four-byte aligned flag at scratch[0:4]
  native callback ds41_compress_finish_scratch: status16-byte prefix plus rounded
  Plan reserve from gpu_scratch_bytes<compress_finish::Plan>()
  native entry: validate -> stage Plan -> reset status -> full-batch preflight ->
  conditional output kernel, all on the supplied stream, enqueue-only
  host entry ds41_ref_compress_finish: private CPU flag, direct negative return;
  never dereferences caller DEVICE/NULL/PROT_NONE scratch and allocates no workspace
Parent registration must attach the existing scalar deferred-status collector to
the GPU row, and none to the HOST row. Do not mark this op collective, release-link
or concurrent/chain-safe without a separate audit. The caller must await Core's
device status before publishing cache state. Core scratch/status ownership and
existing opted-in tape/speculation restrictions are not relaxed.

New file integration (parent owns existing CMake/row-table changes and all builds):
  ds41_compress_finish.h: metadata validate/schema/shape/native scratch contracts
  ds41_compress_finish_impl.h: shared bounded scalar equations/preflight
  ds41_compress_finish_emulate.h: transactional HOST semantic emulator
  ds41_compress_finish_host.cpp: actual private-flag HOST row launcher
  ds41_compress_finish.hip: native staged-Plan kernels
  ds41_compress_finish_fixture.h: bounded independent reference-composition fixture
  ../tests/ds41_compress_finish_test.cpp: seven ordinary CPU test bodies
  ds41_compress_finish_selftest.cpp: explicit native HIP checker, not automatic
Header exports schema/params/operands in namespace rad::ds41::compress_finish and
shape as a possible opd_shape callback. The shape callback REFUSES pairs with
RAD_E_UNSUPPORTED because P is caller-owned and absent from the fixed parameter
set. Declare pairs[P,rotary_dim/2,2] explicitly; generic tools must skip instead of
guessing a context-sized table. Other six operands use M at declaration time.
Compile CPU and HIP code with -ffp-contract=off, no fast math. HIP target gfx1201.
The CPU test also composes existing compress_pool emulator calls, but requires no
plugin, device initialization or model payload. Native checker links the new HIP
source; host.cpp is optional for its payload oracle, which is inline and CPU-only.

CPU source coverage:270 scalar/dimension/ratio/pitch combinations; real odd3+4
compressor chunks against independent ref::Compressor BF16 boundaries; signed
zero; protected inactive pooled/position pages; active position lower/upper/modulo
boundaries; last-row mask/input/table faults; derived input/norm/RoPE cast overflow;
20 malformed metadata cases and12 output aliases; semantic-vs-native reserve and
full-reserve alias refusal; host PROT_NONE caller scratch; unknown pairs shape.
Expected values compose existing independent generic casts, ref::rms_norm and
ref::rotary, not the new normalized/output functions. Full source/padding bytes
are retained for immutability and failure-atomicity checks.

Manual standalone proposal, only in the parent's separately authorized idle window:
  <isolated>/ds41-compress-finish-selftest --run-gpu [device]
Never automatic CTest. The main gate precedes explicit device queries/allocations;
linked HIP fatbinary constructors may run earlier. It requires gfx1201 and uses
a private nondefault HIP stream. Aggregate tensor/scratch/red-zone allocation is
capped at1MiB per live case. Source requests236 good passes,18 atomic
payload failures and33 metadata refusals, including good->bad->good on reused
buffers/scratch and complete rounded scratch/padding guards. F32 numeric tolerance
is4e-6+4e-5*abs(expected); rounded output allows one stored ULP for device sqrt
differences. Inactive zero bits and unrotated/rotated prefix equality are exact.
This native checker does NOT prove actual Core AQL launch, deferred collection,
Core public-buffer binding, distributed ownership or a full compressor-to-cache
graph. No compilation/GPU/performance claim is made by this source handoff.
