Experimental native packed embedding gather (source-only operator)

Schema: params M (maximum tokens, <=65536), N (vocabulary), K (embedding width),
format (iq2_xxs,iq2_xs,iq2_s,iq3_xxs,q5_K,q8_0), y_dtype (f32,f16,bf16).
Operands: token_ids I32[actualM], weight privatePackedDT[N,K], output[y_dtype,actualM,K].
actualM is positive and <=M. IDs and output support positive inner/outer pitches.
Weight metadata is logical [N,K] with strides [K,1], exactly the private dtype
and layout tag already used by ds41_packed_gemm. Its readable native extent is
N*(K/block_values)*block_bytes, not N*K bytes. The native byte decoder allows
unaligned weight payloads; canonical relayout requests allocator alignment256.

Layout/relayout/unrelayout helpers are in ds41_embedding_args.h. They require the
entire exact canonical encoding/plane set accepted by the existing GGUF bridge.
No public a_dtype parameter is needed: the adapter internally supplies a harmless
M=1,a_dtype=f32 to reuse the packed GEMM bridge. Runtime plain U8 descriptors are
refused. Normal synthetic F32 weight creation is unsupported by opd_shape; checks
must supply recorded canonical importer fixtures or explicit native packed rows.

One GPU block owns each token and columns are independent scalar decode -> single
output cast, with no persistent expanded vocabulary. This is a correctness baseline,
not a measured optimized embedding implementation. All token IDs are checked for
0<=id<N across the entire batch before any weight payload is read/output written.
A later invalid ID leaves every output unchanged. No clamping. Any decoded NaN/Inf
is preserved according to scalar decode/output conversion; there is no hidden
finite-weight filtering. Weight, IDs, output and scratch may not overlap; geometry,
pitches, pointer wrap and status/Plan alignment are validated before enqueue.
As elsewhere in this ABI, allocation capacity beyond declared tensor geometry is
trusted; there is no tensor byte-capacity field to independently inspect.

CPU emulator accepts the semantic four-byte status only. ds41_ref_embedding uses a
private local status, never caller/device scratch, and returns payload errors directly.
GPU scratch callback returns gpu_scratch_bytes<Plan>(): first four bytes are status,
bytes4..15 reserved unchanged, then staged Plan in bounded common transport chunks.
The full reserved span is alias/capacity/alignment checked. The same stream stages
Plan, initializes status, preflights all IDs, then gathers. Enqueue RAD_OK alone
is not validation success; the deferred-status collector must read scratch[0:4].
Scratch remains owned until the operation/collector complete. Source tensors stay
immutable/live until completion; there is no host synchronization inside launch.

New compilation dependencies:
  host: libds41/ds41_embedding_host.cpp (prepare + ds41_ref_embedding)
  HIP:  libds41/ds41_embedding.hip
  CPU test: tests/ds41_embedding_test.cpp + embedding_host.cpp, normal core/libquant
    fixture linkage and RAD_GOLDEN_FIXTURES definition, -ffp-contract=off.
  staged native checker: libds41/ds41_embedding_selftest.cpp + embedding.hip +
    embedding_host.cpp, hipcc --offload-arch=gfx1201 -Iabi -Ivendor -ffp-contract=off.
The checker requires explicit --run-gpu [device], never runs automatically, uses
only tiny synthetic native blocks, guards all allocations/read-only inputs/padding,
and checks payload status separately from launch status. Exactly234 payload cases
plus25 descriptor refusals, all six formats and three activation output types.
CPU tests use independent GGML goldens and libquant importer -> generic canonical
row decoder, never the new native decoder for expected values. No GPU execution,
model payloads, server API calls, architecture registration or serving changes were
performed by the implementing child.
