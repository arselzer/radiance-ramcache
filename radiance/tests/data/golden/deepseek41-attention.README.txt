Synthetic seed 411017. Six layers: two sliding-window-only, ratio-2 KV producer /
consumer, ratio-1 KV+candidate producer and a new top-k producer sharing its KV.
18 tokens wrap the three-row windows, cross pending compressor groups and exceed
the candidate budget. Two heads/output groups and nontrivial low-rank projections
exercise grouped output and inverse RoPE. Index keys derive from unrotated pooled
latents. Candidates keep two blocks of two positions; newest partial block pinned.

Every projected intermediate, selected index, candidate mask and final output is
checked. Float tolerance was chosen before running: abs 2e-5 + rel 2e-5 for tiny
FP32 NumPy matmul/reduction versus explicitly ordered C++ accumulation. Selection
indices/masks match exactly under a deterministic ascending-position tie rule.
The official framework does not specify equal-score top-k ordering; this fixture
does not promise identical tied choices to Torch. Prefix replay
compares the C++ reference bit for bit across a pending group and ring wrap.

This oracle omits the official FP8/FP4 activation, KV and index quantizers and
output-projection quantization. It cannot establish packed-kernel parity, actual
model quality, TP4 numerics, large-context memory or production throughput.
