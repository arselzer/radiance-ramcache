The reference path has inference/engram.py and inference/model.py below it.
Ordinary tests read only this checked-in JSON and need no external checkout.

The generator extracts each original forward function with the Python AST and
executes its unchanged body with a minimal NumPy CPU tensor facade. Only function
decorators and annotations are removed. No hash RNG, tokenizer normalization or
checkpoint weights are generated: compressed mapping, hash controls, masks and
projected KV values are tiny synthetic inputs. Hashes compare exactly; gate
float32 values use absolute tolerance 3e-6 and gate coefficients 2e-6. Final BF16
residuals compare exactly on these cases. This does not promise bit equality for
arbitrary floating-point reduction orders on a real GPU.

Covered semantics: newest-to-oldest products, order-major/head-minor bucket
layout, compressed pad IDs, cumulative DEAD/image barriers, chunk/decode parity,
per-copy RMS, fused q*k weighting after RMS, signed-sqrt clamp and sigmoid, one
value shared across copies, text masks and final BF16 output rounding.
Zero-query and zero-key cases execute the actual source: copysign retains a
positive signed square-root clamp at dot=+0 (gate about 0.50025), rather than
replacing it with sign(0)*sqrt(...) and changing the gate to 0.5.

This proves small operator/history behavior, not a complete architecture, real
model quality, 262K context capacity, SSD cache behavior or GPU performance.
