Synthetic lossless GGUF importer oracle

No model weights. All 19 standard formats advertised by libquant's importer.
Four rows of 256 values each; seed 1017. Random code fields and selected finite
positive/negative/subnormal/zero half scales. The older research stress proof
also covers 64 scale/code trials across the 10 candidate checkpoint formats.
Expected f32 words come only from an independent GGML decoder. Signed zero is
compared numerically; other finite f32 values must agree exactly.

Reference: https://github.com/vincalkr/DS41Engine

The generator imports no GGML implementation into this repository.

Reproduce from the repository root with DS41_REF pointing at that source tree:

  gcc -std=c11 -O1 -ffp-contract=off -ffunction-sections -fdata-sections -D_GNU_SOURCE \
    -I "$DS41_REF/third_party/llama.cpp/ggml/include" \
    -I "$DS41_REF/third_party/llama.cpp/ggml/src" \
    -c "$DS41_REF/third_party/llama.cpp/ggml/src/ggml-quants.c" -o /tmp/gguf-oracle.o
  g++ -std=c++20 -O1 -ffp-contract=off -ffunction-sections -fdata-sections \
    -I abi -I core -I libquant -I vendor -Wl,--gc-sections \
    tests/gen_gguf_import_golden.cpp /tmp/gguf-oracle.o -pthread -lm -o /tmp/gguf-golden
  /tmp/gguf-golden tests/data/golden/gguf-import.json

Fixture byte strings use little-endian IEEE-754 f32. This generator is intended
for the little-endian x86/AMD target. Generation is optional; ordinary tests read
the checked-in fixture and need no external repository.
