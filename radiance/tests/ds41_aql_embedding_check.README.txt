Explicit native embedding Builder/Ctx/AQL gate (never automatic)

ds41_aql_embedding_check.cpp is deliberately not *_test.cpp. Parent adds its
explicit manual target, linked to HIP-enabled rad_core (WHOLE_ARCHIVE plus
ENABLE_EXPORTS as for the other AQL checkers), with libds41/libquant build
dependencies and -ffp-contract=off. No child compiler/GPU run is implied.

Only in an approved idle window, from a separate process:
  env -u HIP_VISIBLE_DEVICES ROCR_VISIBLE_DEVICES=0 \
    <build>/tests/ds41-aql-embedding-check --run-gpu \
      --home <build>/radiance_home \
      --fixtures <source>/tests/data/golden/gguf-import.json
Repeat in another process with --host-kargs for forced pinned-host argument
storage. It requires explicit --run-gpu, one visible gfx1201 and actual AQL;
host fallback/multiple GPUs are refused. Linked HIP registration constructors
may run before main: the flag gates explicit queries/allocations/launches, not
pre-main loader initialization. Only execute with the flag in an approved window.

All six native formats use recorded four-row256-wide GGML blocks and independent
F32 decoded goldens. Real libquant imports every canonical plane, actual Builder
resolves the new ds41_embedding row and its private stored layout, and the real
row relayout must reproduce the original block bytes exactly. A rotated-vocabulary
variant is independently imported/repacked to make relocation change numeric
answers. Each format runs F32/F16/BF16 outputs. No emulator generates expectations:
expected output is a selected independent GGML row plus one public-ABI scalar cast.
F32 checks use2e-6+2e-5*abs(reference); F16/BF16 cast bytes must match exactly.

NO launch replacement/delegating shim is installed. Actual Ctx binds shaped IDs
and guarded output buffers, plus the opaque native weight, and rad_issue launches
the unmodified registered GPU operation and its scalar deferred-status collector
on ONE reused core stream. After await, the checker reads back the ACTUAL staged
embedding Plan from scratch+device_plan_offset and asserts logical private[N,K]
descriptor, native readable span, actual sliced buffer pointers and relocated
weight pointer. This readback seam is intentionally limited to ONE op per pass:
core run_pass resets its scratch cursor, so that op stages at scratch base+16.
It is an internal checker observation, not a new runtime ABI.

Each of18 fixtures runs good -> invalid LAST ID -> good, then a new VRAM record
with rotated vocabulary, then a mapped-host original record, invalid-last-ID and
good again. BOTH invalid passes must enqueue successfully, return RAD_E_SHAPE
through Ctx::await_device_status with op attribution, preserve ALL output bytes,
and recover on the next valid pass. Opted graphs must not replay. Old and current
weight records remain alive and byte-identical through the final reader.

Five token rows include first/last/repeated/interior vocabulary IDs. Input IDs
have256B guards on each side; output has a whole guard row before/after. Explicit
native buffers have256B redzones. Ctx arena+scratch are actual Program-sized and
capped128KiB; aggregate requested fixture data plus the padded Ctx arena are
capped1MiB BEFORE allocation. Canonical CPU importer planes are separately capped
64KiB total per variant. There is no Pools, KV carve, full weight/model read,
service call, production configuration or restart. Core stream rings, module/
driver/page metadata and fixed Ctx status resources are additional and disclosed.

Expected receipt:90 good/36 refused passes,115200 checked golden output values,
all six formats x three output types, VRAM/mapped relocation and flag-reset proof.
This is one-GPU integration correctness, not TP4 vocabulary sharding, full graph
model quality, context fit, speed or cache lifetime proof.
