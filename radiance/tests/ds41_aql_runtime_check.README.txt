Explicit tiny Builder/Ctx/AQL checker (experimental, never automatic)

ds41_aql_runtime_check.cpp is deliberately not *_test.cpp. Parent adds an explicit
target linked to HIP-enabled rad_core (prefer WHOLE_ARCHIVE + ENABLE_EXPORTS),
libds41 and libquant as build dependencies, with -ffp-contract=off for CPU math.
No model, architecture plugin, Pools, configured VRAM carve or server is used.

After an isolated build and approval for an idle GPU window:
  env -u HIP_VISIBLE_DEVICES ROCR_VISIBLE_DEVICES=0 \
    <build>/tests/ds41-aql-runtime-check --run-gpu \
      --home <build>/radiance_home \
      --fixtures <source>/tests/data/golden/gguf-import.json
Repeat in a new process with --host-kargs to cover small-BAR argument placement.
The main function refuses missing --run-gpu before any explicit device query,
allocation or launch. Linked HIP fatbinary registration constructors may run
before main; this is not a promise to suppress native runtime initialization.
Only execute this binary with the flag in an approved idle window. It also
refuses host fallback, multiple visible devices, or an architecture other
than gfx1201. --help performs no explicit device query. No install/deploy/restart is involved.

Covers all six native formats through actual importer, Builder layouts, Ctx
logical private descriptors, real libds41 launch, one engine-owned AQL stream,
WTAB updates and VRAM/mapped-host relocation. CPU answers use the independent
GGML golden logical values. Every explicit buffer has 256-byte redzones and the
aggregate live explicit allocation cap is 1 MiB (normally far smaller). The
Program arena/scratch are separately capped at 64 KiB each; there is no Pools/KV.
Core AQL queue/runtime overhead is additional (roughly 4 MiB argument ring plus
8 MiB pinned bounce for the one reused stream), as printed in the receipt.

Dense-only graph must execute real recorded replay. Routed graph requires the
new versioned collector, awaits Ctx::await_device_status before examining output,
asserts no replay, verifies malformed route refusal and a subsequent valid reset.
Status output is checked independently. The capture wrapper delegates the real
launch; it does not replace the GPU computation with a validator.

This is a small integration gate, not inference/model-quality, multi-rank,
context-fit, cache/loan lifetime, or throughput evidence. Child has not compiled
or executed this checker; parent coordinates all compiler/GPU work.
